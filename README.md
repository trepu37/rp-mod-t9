# RP Autocomplete — «T9» для RP-отыгровок (Minecraft 1.21.8, Fabric)

Клиентский мод: вы набираете короткое сокращение (`/me дост`), мод показывает над чатом
готовую отыгровку, **Tab** вставляет её в поле ввода. Ничего не отправляется само —
Enter вы нажимаете сами. На сервер ставить ничего не нужно.

---

## Что умеет

1. **Подсказка отыгровок по сокращениям** — `/me дост` → готовая отыгровка (Tab вставляет).
2. **Т9 по словам** — как в браузере/телефоне: пишете `греч` → мод предлагает `гречка · греческий · гречневый`.
   Словарь: **до 100 000 самых частых русских слов** (живая разговорная речь) + все слова из ваших шаблонов.
3. Меню шаблонов (клавиша **K**): добавить, изменить, удалить, категории, поиск, избранное, импорт/экспорт JSON.

## 1. Как получить JAR (выберите ОДИН способ)

### Способ А — без установки программ (GitHub, бесплатно)

1. Зарегистрируйтесь на https://github.com и нажмите **New repository** → имя `rp-autocomplete` → **Create repository**.
2. На странице репозитория нажмите **uploading an existing file**.
3. Распакуйте архив с проектом и **перетащите всё содержимое папки** в окно браузера
   (вместе со скрытой папкой `.github`). Нажмите **Commit changes**.
   - Если папка `.github` не загрузилась: **Add file → Create new file**, имя `.github/workflows/build.yml`,
     вставьте туда содержимое одноимённого файла из архива.
4. Откройте вкладку **Actions** → запустится «Build mod» (3–6 минут). Если не запустился — выберите его и нажмите **Run workflow**.
5. Когда появится зелёная галочка, откройте запуск → внизу **Artifacts** → скачайте `rp-autocomplete-jar` → распакуйте.
   Внутри будет `rp-autocomplete-1.1.0.jar`.

Если вместо галочки красный крестик — откройте запуск, скопируйте текст ошибки и пришлите его.

### Способ Б — на своём компьютере (Windows)

1. Установите **JDK 21** (https://adoptium.net, Temurin 21).
2. Распакуйте проект, дважды щёлкните **`build.bat`** (скачает Gradle сам, нужен интернет).
3. JAR появится в папке `build\libs\` — берите файл **без** `-sources` в названии.

### Способ В — вручную (для опытных)

Нужны JDK 21 и Gradle 8.14.x: `gradle build` → `build/libs/rp-autocomplete-1.1.0.jar`.
Если Gradle ругается на версию Loom, в `gradle.properties` попробуйте `loom_version=1.12-SNAPSHOT` или `1.10-SNAPSHOT`.

## 3. Управление

| Действие | Клавиша |
|---|---|
| Открыть меню отыгровок | **K** (в игре, не в чате) |
| Быстро включить/выключить автодополнение | **F8** (работает и в чате) |
| Вставить выбранный вариант (отыгровку или слово) | **Tab** |
| Выбрать вариант | **↑ / ↓** (если вариантов 2+), **Shift+Tab** — следующий по кругу |
| Вставить вариант по номеру | **Alt+1 … Alt+9** |
| Отправить | **Enter** — как обычно, отправляется только то, что в поле ввода |

K и F8 меняются в **Настройки → Управление → RP-отыгровки**.
Tab / ↑ / ↓ меняются в меню мода → **Настройки**. Для них выбирайте не буквенные клавиши.

## 4. Как пользоваться автодополнением

После установки уже есть демо-шаблоны. Откройте чат (T) и попробуйте:

| Вводите | Получаете |
|---|---|
| `/todo здр` | `/todo Здравствуйте. Предъявите, пожалуйста, документы для проверки.` (+ второй вариант) |
| `/me дост` | `/me достал удостоверение из внутреннего кармана куртки и предъявил его собеседнику.` |
| `/rp проверка` | 4 варианта: проверка документов, задержание, обыск, медпомощь |
| `Здравствуйте, предъявите документы` | сохранённая фраза с таким началом (T9 по тексту) |
| `/rp ` (с пробелом) | все шаблоны: избранные и недавние сверху |
| `/rp мед` | поиск по сокращениям, названиям, тексту и категориям |

Правила, чтобы мод не мешал игре:

- Работает только внутри **RP-команд**: `me, do, todo, try, ame` (список меняется в настройках) и в обычном тексте.
  Команды вроде `/gamemode`, `/tp` **не затрагиваются**.
- Если подсказок нет — Tab, стрелки и Enter работают как в обычном Minecraft.
- В обычном тексте подсказка появляется только от 3–4 символов, чтобы не мигать при болтовне.
- Подсказки строятся по тексту **до курсора**; всё, что правее курсора, при вставке сохраняется
  (так шаблон вставляется «в текущую позицию»).
- **Защита от случайной отправки:** сразу после вставки Enter блокируется на 0,7 с
  («Проверьте текст и нажмите Enter ещё раз»), настраивается или выключается.
  Если в шаблоне есть `{заполнитель}` (например, `{имя}`), он выделяется — просто начните печатать поверх;
  пока он остаётся в тексте, Enter не отправит сообщение.
- Лимит чата — 256 символов; если текст длиннее, мод предупредит.

## 4а. Т9 по словам (как в браузере)

Если подходящей отыгровки нет, мод подсказывает **слова**. Над полем ввода появляется строка:

`1 гречка   2 греческий   3 гречневый   4 гречишный   5 греческом        Tab — вставить`

| Действие | Клавиша |
|---|---|
| Вставить первое слово (подставляется целиком + пробел) | **Tab** |
| Следующее слово по кругу | **Shift+Tab** |
| Слово по номеру | **Alt+1 … Alt+9** |

- Стрелки ↑/↓ в режиме слов **не трогаются** — история чата работает как обычно.
- Подсказка от **2 букв** (меняется в Настройки → «Т9 по словам...»).
- Регистр сохраняется: `Греч` → `Гречка`.
- Работает в обычном тексте и внутри RP-команд (`/me`, `/do`, `/todo`, `/try`, `/ame`).
  В остальных командах (`/gamemode`, `/tp`...) слова не подсказываются.
- Слова из **ваших шаблонов** предлагаются первыми — чем больше своих отыгровок, тем точнее подсказки под вашу роль.
- Свои слова (имена, термины, сленг сервера) можно дописать в файл `.minecraft/config/rpautocomplete/words.txt` — по одному слову в строке, они будут в приоритете.
- Матерные слова по умолчанию **не подсказываются** (можно включить в настройках).
- Настройки Т9: вкл/выкл, количество слов (1–9), с какой буквы, пробел после слова, скрывать мат.

Словарь — частотный список русского языка FrequencyWords (Hermit Dave) по субтитрам OpenSubtitles,
лицензия **CC-BY-SA 4.0**; скачивается при сборке, в этом архиве не лежит.

## 5. Как добавить свою отыгровку

1. Нажмите **K** → **Добавить**.
2. **Название** — для вас (например, «Рация»).
3. **Сокращения** — через запятую (`рц, рация`). Регистр и «ё/е» не важны.
4. **Категория** — впишите свою или нажмите **Сменить**.
5. **Текст** — целиком, **вместе с командой**: `/do Рация закреплена на плече.`
   Текст без команды (`Здравствуйте...`) тоже можно — тогда при вводе внутри `/me`, `/do` он подставится после вашей команды.
6. **Сохранить**.

**Несколько вариантов для одного сокращения:** выберите шаблон → **+ Вариант** → поменяйте текст.
Или просто создайте новые шаблоны с тем же сокращением — все они появятся списком.

Остальное в меню: поиск, фильтр по категории, показ «Все / Избранное / Недавние», **★ Избр.** (закрепить),
**Удалить** (с подтверждением), двойной клик по строке — изменить, **В чат** — открыть чат с этим текстом.

## 6. Импорт и экспорт (JSON)

- **Экспорт** — файл `rp-templates-<дата>.json` в `.minecraft/config/rpautocomplete/export/`
  и копия JSON в буфер обмена (можно отправить другу в мессенджере).
- **Импорт: файл** — положите `.json` в `.minecraft/config/rpautocomplete/import/` и нажмите кнопку.
- **Импорт: буфер** — скопируйте JSON-текст и нажмите кнопку.
- Повторы (тот же текст и сокращения) пропускаются.

Все данные хранятся в `.minecraft/config/rpautocomplete/` (`templates.json`, `settings.json`) в UTF-8
и сохраняются между запусками. Если `templates.json` повредится — мод сделает копию `templates.broken-*.json`.

Формат файла:
```json
{
  "format": "rpautocomplete-templates",
  "version": 1,
  "templates": [
    {
      "title": "Показать удостоверение",
      "category": "Полиция",
      "text": "/me достал удостоверение и предъявил его.",
      "abbreviations": ["дост", "уд"],
      "favorite": true
    }
  ]
}
```
(Поля `id`, `uses`, `lastUsed` необязательны.)

## 7. Если что-то не работает

- **Подсказки не появляются:** нажмите F8 (возможно, выключено); проверьте, что команда есть в списке RP-команд (Настройки);
  сокращение набрано целиком (минимум 2 символа внутри команды).
- **Tab не вставляет, а предлагает ники/команды:** у сервера свои подсказки — Tab у мода приоритетнее только когда виден наш список.
- **Кнопки меню налезают друг на друга:** уменьшите «Масштаб интерфейса» в настройках видео (до 2–3).
- **Ошибки сборки / вылет игры:** пришлите текст ошибки / `logs/latest.log`.

## 8. Устройство проекта

```
src/main/java/ru/rpautocomplete/
  RpAutocompleteClient.java   точка входа, клавиши K и F8
  ChatAutocomplete.java       список над чатом, Tab/стрелки, защита Enter (события Fabric API, без миксинов)
  SuggestionEngine.java       правила подбора подсказок-отыгровок
  WordDictionary.java         Т9 по словам: словарь до 100 000 слов + слова из шаблонов
  Template.java, TemplateStore.java, Settings.java, Categories.java   данные и JSON
  gui/ManagerScreen.java, EditScreen.java, SettingsScreen.java, WordSettingsScreen.java   меню, редактор, настройки
```
Мод не меняет сетевые пакеты, ничего не отправляет автоматически и не содержит макросов.
